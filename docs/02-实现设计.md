| D46 | **runtime 是单一真源**：`templates/src/runtime.js` 用 esbuild text loader 打进插件，模板构建和插件注入读同一份 | 不会出现「模板里是一套、插件里是另一套」 |
| D47 | **正文根兜底链**：`#content` → `main` → `article` → `body`；退到 body 时排除 `nav/aside` 内的元素 | 外部网页没有 `#content` 也能用；标注不会锚到目录上 |
| D48 | **笔记与标注改成悬浮面板**：脱离文档流的 fixed 面板 + 右侧 18px 把手，默认收起 | 常驻在正文流里会挤占正文宽度，网格布局的页面甚至被排到右列去 |
| D49 | **不碰页面排版**：runtime 不再全局设置 `box-sizing`，只约束自己的界面元素；页面滚动交给 `scrollHost()` 抽象 | 插件不能改用户页面的布局；自定义滚动容器的页面也能正确翻页 |
| D50 | **瞬时翻页必须压过页面自己的 `scroll-behavior`**：滚动前把滚动元素的 `scroll-behavior` 临时压成 `auto`，并用 `behavior:"instant"` 兜底 | 普通网页常带 `html{scroll-behavior:smooth}`，会把翻页变成动画；墨水屏上这是硬伤 |
| D51 | **CDP 触摸坐标不能写死偏移**：沙箱 iframe 被拆到独立进程时触摸用「顶层窗口坐标」，同进程时用「iframe 内部坐标」，同一台机器上会变 | 验收脚本改为**现场校准**：发一个探针点，回读页面收到的 `clientX/clientY`，用差值修正后续派发 |
| D52 | **验收脚本收尾自己关标签页**：只 detach 路径含 `html-view-test/auto-` 的 HTML 视图，不碰用户的 `demo-*` | 验收不能给用户工作区留垃圾 |
| D53 | **G8 样例页必须足够长**：翻页断言按「最大滚动量」位置感知，不用写死的 `scrollTo(0,600)` | 页面太短时 `scrollTo` 被钳到最大值，测的就不是翻页而是「页面只有一屏半」 |
| D54 | **写盘放大倍数的真值**（实测）：打开 0 次、关闭 0 次、连续 5 次操作合并成 1 次、滚动跨章节 1 次、每次标注 1 次 | 之前「打开文件就回写」的推断是错的（`saveNow()` 在 `mergeLocal()` 里，不在 `applyProgress()` 里）；同步流量方案据此重排 |
| D55 | **同步流量的唯一可调项是「写盘次数」**：WebDAV `PUT` 全有或全无，插件侧无法把单次上传变小 | 写回策略（合并延迟 / 手动）成为方案 A；进度单独存文件（方案 D）需用户解除「零附属文件」约束 |

> 三处按你的答复直接落地、不再单独问：`tags`/`category` 预留空位；`reviewQueue` 取消；`answers[q].at` 时间戳。

## 3. 数据契约 v1（唯一真相源）

```jsonc
{
  "meta": { "schema": "html-quiz-progress/v1", "updatedAt": "2026-11-04T15:10:00.000Z", "updatedBy": "device-8f2a1c" },

  "currentQuestion": 3,

  "answers": {
    "q1": { "value": "B", "at": "2026-11-04T15:02:00.000Z", "why": "我的思路", "wrongReason": "自由文本" },
    "q2": ["A", "C"],
    "q3": "D"
  },

  "scrollY": 1200,
  "scrollPercent": 42,
  "readDone": false,

  "sectionProgress": {
    "s1": { "title": "第一章 …", "percent": 100, "read": true, "at": "2026-11-04T15:05:00.000Z" },
    "s2": { "title": "第二章 …", "percent": 34,  "read": false }
  },

  "notes":       [ { "id": "n1", "text": "未分类灵感也放这儿", "at": "…", "tags": [], "category": "" } ],
  "annotations": [ { "id": "a1", "text": "这句没跟上", "quote": "被选中的原文", "occurrence": 1, "doubt": false, "at": "…", "tags": [], "category": "" } ],
  "marks":       [ { "id": "m1", "text": "这里要回头看", "y": 1280, "quote": "最近段落首80字", "doubt": false, "at": "…", "tags": [], "category": "" } ],

  "ui": { "pager": { "x": 24, "y": 24 } }
}
```

**字段规则**

| 字段 | 类型 | 规则 |
|---|---|---|
| `answers[q].value` | string \| string[] | 单选为字符串，多选为数组；未作答时该键不存在 |
| `answers[q].at` | ISO 时间 | 题级时间戳，合并的裁决依据 |
| `answers[q].why` | string | 用户的思路/理由（自由文本） |
| `answers[q].wrongReason` | string | 选错原因（自由文本，待 AI 归类） |
| `answers[q]` 裸值 | string \| string[] | 兼容需求原文的 `{currentQuestion, answers:{q1:"B"}, scrollY}` 写法；读取时归一 |
| `annotations[].quote` + `occurrence` | string + int | quote 锚点；occurrence = 该文本在全文第几次出现（从 1 起） |
| `marks[].y` + `marks[].quote` | number + string | 位置锚点：滚动位置 + 最近段落首 80 字（双保险：y 失效时用 quote 模糊定位） |
| `doubt` | bool | 存疑标记；`text` 可空 |
| `tags` / `category` | string[] / string | 预留空位，后期由 AI 回写分类建议 |
| `meta.updatedAt` | ISO | **每次写入由插件盖章**（插件是写入权威） |
| `meta.updatedBy` | string | 设备标识（`device-xxxx`） |

**演进策略**：`meta.schema` 升版时，读取端按「缺字段用默认值、未知字段忽略」处理，保证老文件永远能打开。

## 4. 内容元数据块契约（静态内容，AI 生成时写入）

```html
<script id="html-content-meta" type="application/json">
{
  "title": "2026 年 11 月 AI 行业观察",
  "kind": "article",                       // article | quiz | mixed
  "sections": [
    { "id": "s1", "title": "第一章 模型进展", "kind": "article" },
    { "id": "s2", "title": "第二章 产品动态", "kind": "article" }
  ],
  "questions": [
    { "id": "q1", "stem": "题干…", "options": ["A. …", "B. …"], "answer": "B", "explain": "解析…" }
  ]
}
</script>
```

- 这块是**静态内容**，插件**不写它**（插件只写进度块）→ 不影响写回手术
- 页面运行时用它做**判分**（D14）与**一致性校验**（D15）
- Agent 取数时：一次 grep 进度块（用户产出）+ 一次 grep 本块（题目与标准答案）→ 自行推导对错与复习清单（D23）

## 5. 标记采集规范（D16–D22、D24–D26）

### 5.1 三种采集入口

| 入口 | 操作 | 产出 | 锚点 |
|---|---|---|---|
| **选中文字** | 选中正文 → 浮出按钮组 `💬 评注` / `❓ 存疑` | `annotations[]` 一条 | `quote` + `occurrence` |
| **位置标记** | 底部常驻 `📍 标记此处` | `marks[]` 一条 | `y` + 最近段落 `quote` |
| **随手笔记** | 底部 `＋ 新笔记` | `notes[]` 一条 | 无锚点（全局） |

- `💬 评注` 与 `❓ 存疑` 都走「选中文字」入口：**存疑只多一个「文字可跳过」的小框**（D17）
- 位置标记同样支持 `doubt:true`（在标记弹出的输入框里勾「这是我不懂的」）

### 5.2 锚点回找（D16 / D22）

- 点击底部列表任一条 → 页面滚动到锚点位置 + **闪烁高亮 1.5 秒**
- quote 锚点回找：取全文该 quote 的第 `occurrence` 次出现；找不到 → 退化为「最近包含首个 12 字的段落」→ 再找不到 → 提示「原文已改动，锚点失效」
- 位置锚点回找：优先用 `y`（误差 > 视口高度 50% 时失效），失效则用 `quote` 模糊定位

### 5.3 正文痕迹（D22）

- 被评注/存疑的选中文本 → 淡黄底（`rgba(255, 214, 102, .38)`）+ 下划虚线
- 被位置标记的段落 → 左侧 3px 竖线 + 序号徽标
- 颜色走 CSS 变量，适配墨水屏（`@media (prefers-contrast: more)` 下加深描边）

### 5.4 章节级阅读（D24–D26）

- 章节来源：**显式 `<section data-sid data-stitle>` 优先**；没有则按 h2/h3 自动切分
- 章节已读判定：**该章节最后一个元素进入视口 → 置 `read:true`**（D25），同时记录该章 `percent`
- 整篇已读：滚动百分比 ≥95% → `readDone:true`；**手动按钮可撤销**（D26）
- 章节进度写入 `sectionProgress[sid]`，随进度一起同步

### 5.5 答题页的思路与原因（D18–D19）

- 每题下方一行折叠的 `✎ 我的思路` 输入框（默认收起，首次聚焦展开）
- 输入即防抖保存 → `answers[q].why`
- 判错后，题目下方出现 `❓ 为什么选错？` 自由文本框 → `answers[q].wrongReason`
- 页面**不自动生成任何标签**，分类留给 Agent

## 6. 文本手术算法（D01/D02/D08）

```ts
const BLOCK_RE = /(<script\b[^>]*\bid=["']html-quiz-progress["'][^>]*>)([\s\S]*?)(<\/script\s*>)/i;
```

1. `text = await vault.read(file)`
2. `m = BLOCK_RE.exec(text)`
3. **命中** → `text.replace(BLOCK_RE, (_, open, _old, close) => open + serialize(payload) + close)`（open/close 原样保留）
4. **未命中** → 找最后一个 `</body>`，在其**前**插入完整区块；没有 `</body>` 则追加到文件末尾
5. **序列化**：`JSON.stringify(payload, null, 2)`，再做三处转义（见下）
6. `await vault.modify(file, newText)`

### 6.1 三处必做转义（否则整个页面当场损坏）

| 原始数据 | JSON 文本 | 危害 |
|---|---|---|
| `</script` | `<\/script` | **提前闭合 script 标签**，后续正文被当脚本吞掉 |
| `<script` | `<\u0073cript` | 进入 script double-escaped 状态，`</script>` 不再结束脚本 |
| `<!--` | `<\u0021--` | 进入 script escaped 状态，结束标签行为改变 |

三条转义都在 `JSON.stringify` **之后**作用于 JSON 文本本身，因此 `JSON.parse` 结果与原 payload 完全一致（`\/`→`/`，`\u0073`→`s`，`\u0021`→`!`）。

### 6.2 边界情况

| 情况 | 处理 |
|---|---|
| 区块存在但 JSON 非法 | 覆盖重建 + 页面提示「进度区已损坏并已重建」+ 日志 |
| 多个同 id 区块 | 只替换**第一个**，其余保留 + 日志告警 |
| `vault.modify` 失败 | 捕获 → 页面红色提示 + 重试按钮，**内存数据不丢** |
| 保存瞬间被外部改写 | 写回前重读比对（D28） |

### 6.3 幂等性

同一 payload 连存两次 → 第二次产出与第一次**逐字节相同**。这是同步 diff 不爆炸的前提，写进单测。

## 7. 消息协议与安全（D06/D07/D35）

| 方向 | `type` | 载荷 | 说明 |
|---|---|---|---|
| iframe → 插件 | `LOAD_PROGRESS` | 无 | 请求读取本文件进度 |
| iframe → 插件 | `SAVE_PROGRESS` | `{ payload }` | 提交新进度 |
| 插件 → iframe | `HTML_QUIZ:PROGRESS` | `{ payload, pluginVersion, source:"plugin" }` | 返回进度 + 确认处于插件环境 |
| 插件 → iframe | `HTML_QUIZ:ACK` | `{ ok, savedAt?, error? }` | 保存回执 |
| 插件 → iframe | `HTML_QUIZ:SELFTEST` | `{ steps }` | **仅开发自检**，跑脚本化交互做端到端验证 |

**校验链**（插件侧逐条执行）：
1. `event.source === iframe.contentWindow` —— 只认自己那个 iframe
2. `event.data` 是普通对象，`type` 在白名单内
3. `SAVE_PROGRESS.payload` 是普通对象（非数组/非 null），序列化 ≤ 2 MB
4. 清洗：`__` 前缀键丢弃、嵌套深度 ≤ 8、字符串长度上限
5. **目标文件恒为 `this.file`**，消息无法指定任何路径（D07）
6. `event.origin` **不硬校验**：沙箱下 iframe 是不透明源，origin 恒为 `"null"`，安全性由 source 校验 + 沙箱承担（文档明示，避免误读为漏检）

## 8. 合并契约（D09/D10/D11）

```
merge(disk: ProgressBlock, incoming: ProgressBlock) -> { merged, keptFromDisk }
```

| 字段 | 规则 |
|---|---|
| `answers` | 按题号合并；同题比较 `at`，缺失 `at` 视为更旧；只在一侧的题保留 |
| `notes` / `annotations` / `marks` | 按 `id` 合并；同 id 比较 `at`；**`deleted:true` 为终态（删除胜）**；墓碑保留 |
| `sectionProgress` | 按 `sid` 合并；同 sid 取 `at` 新者；**`read:true` 优先于 `false`**（读过不因另一端旧数据回退） |
| `scrollY` / `scrollPercent` / `currentQuestion` / `readDone` | 取 `meta.updatedAt` 较新的一方（last-write-wins） |
| `meta` | 取较新一方的 `updatedAt`；`updatedBy` 记写入方 |

**冲突提示**：合并完成后，若某字段最终采用了磁盘侧的值 → 顶部提示「已保留另一端修改的 N 处」；否则静默合并。

**写回流程**
```
收到 SAVE_PROGRESS
 → 取本文件锁（串行）
 → 重新读盘 → 提取磁盘进度 → merge(disk, incoming)
 → 冲突检测：disk.meta.updatedAt ≠ 我们上次写入的值 → 提示「该文件在其他设备被更新过」
 → 文本手术 → vault.modify
 → 更新内存基线 → 回 ACK
```

**墓碑清理**：命令「清理已删除条目」——移除 `deleted:true` 的墓碑（同步后其他设备也清理不了，所以是本地整理动作，UI 上注明）。

## 10. 模板运行时规格（D31–D35）

| 模块 | 规格 |
|---|---|
| 翻页键 | 右侧**垂直居中**的上下三角（`▲`/`▼`），可拖动、**opacity 0.4**（hover/拖动时 0.85）、命中区 36×36、两个箭头之间留 44px 拇指间隔；点击**瞬时**滚动一屏（视口 90%，`behavior:"instant"` 不做平滑动画）；拖动位移 >6px 视为拖动不翻页；位置存 `ui.pager = { top: 0~1 比例, right: 像素 }`（旧版 `{x,y}` 自动迁移） |
| 触屏分区翻页 | 非画笔模式下，**点按**（位移 ≤10px、时长 ≤400ms、目标非交互元素、无选区）才触发：上半屏向上、下半屏向下；**滑动一律交给原生滚动**；画笔模式下完全不参与 |
| 图片 | 默认缩略（`max-height: min(240px, 30vh)`）；双击 → **等宽**（100vw）；再双击 → **全屏**（优先 `requestFullscreen`，失败退 CSS 满屏）；第三次双击回缩略；ESC / 点背景关闭；触屏用双击手势（300ms 内两次 touchend） |
| 章节锚点 | 按 D24 切分并给每章生成锚点 id（供底部列表与后续跳转） |
| 降级 | `window.parent === window` → 立即降级；否则 600ms 未收到 `HTML_QUIZ:PROGRESS` → 降级；降级用 localStorage（try/catch，opaque origin 抛错则退内存）；横幅文案「当前不在自定义 HTML 视图，进度无法跨设备同步」；后续握手成功 → 合并本地缓存并立即写回 |
| 防抖保存 | 500ms；另有手动「保存进度」按钮；页面内显示「已保存 HH:MM:SS / 保存失败+重试」 |
| 状态恢复 | 恢复当前题号、已选项、滚动位置、章节进度、笔记、标注、翻页键位置 |
