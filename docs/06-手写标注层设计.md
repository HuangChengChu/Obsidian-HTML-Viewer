## 1. 目标与边界

**做什么**：在 HTML 页面上加一层可手写的 SVG 画布，支持阅读时圈画、做题时打草稿；
部分笔迹可保存进文件、跨设备接力；草稿可一键清屏。

**不做什么**（明确排除，避免功能膨胀）：
压感与笔锋、形状识别、图层、缩放上限可调、每题独立草稿框（**后续再做**）、笔迹转文字。

**轻量约束**：插件侧只改 1 行（合并列表加一个字段）；其余全部落在页面 runtime 里。

## 3. 架构

```
<article id="content">            ← position:relative（运行时设置）
  …正文…
  <svg class="hvv-ink">           ← 运行时注入，绝对定位铺满 content
    <path class="hvv-draft"/>     ← 临时笔迹（内存，不落盘）
    <path class="hvv-saved"/>     ← 已保存笔迹（可单笔擦）
    <path class="hvv-hit"/>      ← 透明宽线，橡皮命中区
  </svg>
</article>

<div class="hvv-inkbar">         ← 固定悬浮工具条，可拖动吸附四边
<div class="hvv-ink-fab">        ← 右下角 ✏️ 按钮（进入/退出画笔）
<div class="hvv-zoom-tag">       ← 右上角「⤢ 200%」+ 还原（仅放大态）
```

**为什么 SVG 放在 `#content` 里面**（而不是 body 或独立层）：
- `position:absolute` + `inset:0` → 尺寸自动跟随 content 高度，不用手动同步
- 缩放时（`transform: scale` 作用在 `#content`）**笔迹跟着正文一起缩放**，坐标换算只需除以缩放比
- 不占布局空间，不影响正文排版

**为什么不包一层 wrapper**：少改 DOM，降低与 AI 生成页面的结构冲突风险。

## 4. 手写层核心机制

### 4.1 笔迹数据

```jsonc
"strokes": [
  { "id": "s1", "d": "M12,30 C40,28 55,60 80,58",
    "color": "ink",          // 语义键：ink | red | yellow | blue
    "width": 4,              // 2 | 4 | 8
    "opacity": 1,            // yellow 固定 0.45，其余 1
    "anchor": { "text": "被圈住的那段话前 40 字", "dx": 12, "dy": -18 },
    "at": "2026-11-05T…", "saved": true }
]
```

- `d`：SVG 路径（相对坐标 + 圆角线帽），矢量、体积小
- `color`：语义键而非十六进制 → 暗色主题下 `ink` 自动反白，存量数据无需迁移
- `anchor`：这一笔贴在哪个块级元素上（段落/标题/列表项/图片/表格行）
  - `text`：该块文本前 40 字（定位用）
  - `dx/dy`：笔迹起点相对该块左上角的偏移（重排校正用）

### 4.2 绘制

- `pointerdown` → 起笔，记录 `pointerId`，`setPointerCapture`
- `pointermove` → 追加路径点（用 `getCoalescedEvents()` 补帧，提高笔迹顺滑度）
- `pointerup` / `pointercancel` → 收笔
- 落笔后 **250ms 内**若收到 `dblclick` → **撤销该笔**并执行放大（避免"想放大却画出两笔"）
- 撤销 = 移除最后一个 draft path（一级撤销）

### 4.3 锚点与重排校正

保存时：
1. 取笔迹起点所在的最近块级元素（`p / li / h1-h4 / td / figure / blockquote`）
2. 记录该块文本前 40 字 + 笔迹起点相对该块的偏移

加载时：
1. 用 `anchor.text` 在 `#content` 里查找匹配块（取第一个命中）
2. 命中 → 把该块下的所有笔迹**整体平移** `Δ = newBlockTop - oldBlockTop`（`oldBlockTop` 存于 anchor 或由首次加载时算出）
3. 未命中 → 退回绝对坐标（笔迹不丢，位置可能偏）

> 平移按「组」处理：同一段落下的笔迹一起动，不会互相错位。

### 4.4 缩放（正文区域放大）

- 双击正文（非图片）→ 以点击点为锚，`#content` 应用 `transform: scale(2)`，`transform-origin` = 点击点相对 content 的位置
- 高度补偿：按变换后的包围盒设置 `margin-top / margin-bottom`，保证可滚动到底
- 滚动补偿：缩放后 `scrollBy` 使点击点仍停在原视口位置
- 笔迹坐标换算：`svgX = (clientX - svgRect.left) / scale`、`svgY = (clientY - svgRect.top) / scale`
- 再双击任意处 → 立即回到 `scale(1)`（I15 快速切换）
- 放大态右上角常驻「⤢ 200%」+「还原」按钮，防止误触卡住
- 缩放比例只做 1x / 2x 两档

### 4.5 笔 / 手指 分派

| 状态 | 触摸（finger） | 笔（pen） |
|---|---|---|
| 自动模式、未识别到笔 | **绘制**（页面滚动锁定，用「☝滚动」放开） | 绘制 |
| 自动模式、已识别到笔 | **跟手滚动**（自实现，不绘制） | 绘制 |
| 「🎯 强制笔模式」开启 | 跟手滚动 | 绘制 |

- 识别方式：监听 `pointerdown`，`event.pointerType === 'pen'` → 标记为笔模式
- 识别不可逆（本次会话内不回退），避免抖动
- 被动电容笔会被系统报成 `touch` → 识别不到 → 自动退回手指模式（可用「🎯」强制）

### 4.6 跟手触摸滚动（笔模式）

```
touch pointerdown → 记录 lastY
touch pointermove → dy = lastY - clientY; window.scrollBy(0, dy); lastY = clientY
```
- 画布 `touch-action: none`（绘制必需）
- 不做惯性（省代码，手感略逊原生但够用）
- 单指滚动；双指不处理

### 4.7 工具条与吸附

```
[🖌 当前笔刷]  [🩹 橡皮]  [🧹 清屏]  [💾 保存]  [🎯 强制笔]  [☝ 滚动]  [✕ 退出]
 └ 点开弹层：4 色 × 3 粗细 九宫格
```

- 一行，**横向可滑动**（移动端窄屏）
- 「🖌」图标本身显示当前颜色与粗细
- 「🎯」「☝」为开关态（亮起=生效）
- 「🧹 清屏」单击清 draft；双击弹确认框 → 清 draft + strokes（strokes 写墓碑）
- **可拖动吸附**：拖动结束后取距最近的边吸附；上/下 = 横排，左/右 = 竖排；吸附位置存 `ui.inkbar = { edge: "bottom" }`，随进度同步
- 工具条 `position:fixed`，吸附后贴在对应边

### 4.8 橡皮

- 每条 path 额外渲染一条**透明宽线**（hit path，宽度 = max(12, width+8)）作命中区
- 橡皮模式下点选 → 命中 path → 删除
  - draft 笔迹：直接移除
  - saved 笔迹：移除并写墓碑 `{id, deleted:true, at}` → 跨设备同步删除
- 只支持点选，不做拖动擦除（命中算法成本高）

## 5. 数据契约增补

进度块新增字段：

```jsonc
{
  "strokes": [
    { "id":"s1", "d":"M12,30 C40,28 55,60 80,58", "color":"ink", "width":4, "opacity":1,
      "anchor": { "text":"…前 40 字", "dx":12, "dy":-18 }, "at":"…", "saved":true }
  ],
  "ui": {
    "pager": { "x":24, "y":24 },
    "inkbar": { "edge":"bottom" }
  }
}
```

**插件侧改动**：仅在 `merge.ts` 的条目数组合并列表中加入 `"strokes"`（按 id 合并 + 墓碑终态）——**1 行**。
其余（提取 / 替换 / 转义 / 并发 / 锁）全部复用既有能力。

**AI 提取契约增补**：

```bash
grep -oP '(?s)(?<=<script id="html-quiz-progress" type="application/json">).*?(?=</script>)' page.html
```
→ `strokes[]`：`anchor.text` 告诉 Agent「用户在哪一段画过」，`width/color` 反映圈画重点的位置与力度感，
但笔画形状本身无语义价值（不做图形识别）。

**降级模式**（非插件环境）：draft 与 strokes 一并存 localStorage（沙箱下退内存），行为一致。

### 9.2 关键实现选择

1. **路径格式**：`M x,y` + 相对 `l dx,dy` 折线。
   相对路径的好处是**平移只需改首点**（`inkTranslatePath`），重排校正与橡皮命中都好算。
   折线配 `stroke-linecap/linejoin:round`，视觉上足够顺滑，且单测可精确断言。

2. **重排偏移不落盘**：校正量存在内存里的 `s.dx / s.dy`，写回时由 `inkStrokeToPersist()`
   剔除。否则两台设备宽度不同 → 各自把笔迹挪到自己的位置 → 互相覆盖、无限抖动。

3. **坐标换算统一走 `getBoundingClientRect()` 反算**：
   `contentLocal = (elRect.top - contentRect.top) / zoom`。
   缩放与不缩放用的是同一套公式（缩放时两个 rect 一起被变换，除以 zoom 自然抵消）。

4. **缩放实现**：`transform: translate(tx,ty) scale(2)` + `transform-origin: 0 0`，
   `tx/ty` 由点击点反算，保证点击点视觉位置不变；再用一个空 div 撑出额外滚动高度。
   只做 1x / 2x 两档，再双击立即回 1x。

5. **橡皮命中**：JS 侧算点到折线的距离（阈值 `max(12, width+8)/2`），
   而非设计稿里写的「透明宽线 hit path」。少一层 DOM，且能在 jsdom 里直接测。

6. **画布 pointer-events**：默认 `none`（不干扰正文的选中文字、图片双击、链接），
   进入画笔模式才切 `auto`。SVG 是替换元素，**必须显式 `width:100%;height:100%`**
   —— 只写 `inset:0` 时它会保持 300×150 的固有尺寸（这是实测踩到的坑，见 9.3）。

### 9.3 真机踩到并修掉的 2 个缺陷

| 缺陷 | 现象 | 根因 | 修法 |
|---|---|---|---|
| 画布只有 300×150 | 笔事件落在正文元素上，完全画不出东西 | 绝对定位的 `<svg>` 是替换元素，`inset:0` + `width:auto` 不会拉伸到包含块 | 显式 `width:100%;height:100%` |
| `inkDialog` 被覆盖 | 双击清屏弹框时抛 `inkDialog is not a function` | DOM 变量名与函数名同名，`var inkDialog = null` 把函数声明覆盖了 | 函数改名 `openInkDialog()` |

> 这两个都是**单测测不出来、只有真机才暴露**的问题——正好印证了
> 「门禁必须包含真机运行」这条规矩。

### 9.4 与设计稿的偏离（已确认可接受）

| 设计稿 | 实际实现 | 原因 |
|---|---|---|
| 每笔一条透明宽线 hit path | JS 侧距离命中 | 少一层 DOM；等价行为；可在 jsdom 单测 |
| 「滚轮锁定」 | 画笔模式锁滚轮，工具条 `☝` 临时放开 | 与 I08「画笔模式锁页面滚动」一致；桌面端可用一个按钮随时放开 |
| 路径「相对坐标」 | 首点绝对 + 其后相对 | 纯相对路径无法在不做整体重算的情况下平移；这个折中让平移变成改一个数 |
